====================================================================================================
1. MISSION & CORE ARCHITECTURAL PHILOSOPHY
====================================================================================================

Pulse Launcher is a bespoke, high-performance personal Android launcher forked from Lawnchair /
Launcher3, engineered exclusively for a single user on modern Android hardware (minSdk 31, targetSdk 35).

It fuses the strongest paradigms of modern mobile interfaces:
  * Mur Launcher: Bento tile grid, modular dashboards, and universal inline search answers.
  * Niagara Launcher: Vertical alphabetical app list, ergonomics, one-handed wave scroll.
  * Nova Launcher: Deep styling flexibility, micro-results search, robust backup system.
  * iOS / One UI: Fluid Dynamic Island overlay, spring-physics motion language, rich Control Center.

CORE TENETS:
  * Zero Bloat / Personal Focus: Strips all telemetry, multi-user workspaces, work profiles, and
    legacy AOSP widget host cruft in favor of tailored, highly integrated components.
  * Jetpack Compose + Launcher3 Backbone: Keeps rock-solid AOSP lifecycle, recents/quickstep
    integration, and icon cache while replacing user-facing UI layers with Jetpack Compose.
  * Single Style Pipeline: A single central theme definition dynamically cascades across icons,
    typography, island overlays, control centers, and workspace slides.
  * Spring-Driven Physics: Universal spring curves (stiffness: 300, damping: 28) with a global
    personality slider (Subtle / Balanced / Expressive).

3. 3-SLIDE WORKSPACE ARCHITECTURE
====================================================================================================

The workspace abandons the traditional static icon grid in favor of three specialized, high-intent
slides connected via horizontal swipe with 0.7x parallax wallpaper offset:

                     [ 3-SLIDE INTERFACE TOPOLOGY ]

  +-------------------+    +-------------------+    +-------------------+
  |   SLIDE 1: FEED   |    |  SLIDE 2: TILES   |    |   SLIDE 3: LIST   |
  | (Glance & Digest) |    | (Bento Dashboard) |    | (Niagara A-Z App) |
  |                   |    |                   |    |                   |
  | [ Weather Hero  ] |    | [2x2] [1x1] [1x1] |    | (A) Audible       |
  | [ Agenda Card   ] |    | [Music] [Bt] [Cam]|    | (B) Brave Browser |
  | [ AI Notif Sum. ] |    | [2x1 Clock/Date ] |    | (C) Camera        |
  | [ Screen Time   ] |    | [4x2 App Folder ] |    | (D) Discord       |
  |                   |    | [1x1] [1x1] [2x1] |    | (E) Email         |
  +-------------------+    +-------------------+    +-------------------+
            <------------------- Swipe ------------------->

* SLIDE 1 (FEED):
  - Dynamic Time & Weather Hero header with dynamic gradient backdrop.
  - Next Calendar Agenda complication reading from device calendar.
  - Notification Catch-Up: Grouped, prioritized notification cards with AI one-line summarization.
  - Digital Wellbeing: Interactive bar chart tracking daily unlocks and screen time.

* SLIDE 2 (BENTO TILES):
  - Highly configurable modular grid supporting 1x1, 2x1, 2x2, and 4x2 cell spans.
  - Sub-pixel drag & drop with magnetic snap-to-grid alignment and haptic ticks.
  - Interactive 3D flip cards: Tap or swipe to toggle between primary status and secondary controls.
  - Themed Folder Dashboards: Expanding an app cluster blooms into a frosted glass sheet.

* SLIDE 3 (VERTICAL APP LIST):
  - Ergonomic Niagara-style single-column list for lightning-fast thumb access.
  - Tactile Wave Fast-Scroll: Draggable vertical A-Z rail with magnification physics and haptic curve.
  - Smart App Suggestions: Contextual row at top predicting next app based on time, day, and Wi-Fi.
  - Biometric Private Space: Gated section for protected apps via Android 15 PrivateSpace API.

----------------------------------------------------------------------------------------------------
5.1. DYNAMIC ISLAND & MULTI-PROVIDER AI ENGINE
----------------------------------------------------------------------------------------------------

The Dynamic Island operates as an independent system overlay (`TYPE_APPLICATION_OVERLAY`) running in
a persistent foreground service. It morphs seamlessly across three physical states:

  +-----------------------+     +-------------------------------+
  |   COMPACT (36dp pill) | --> |   EXPANDED (280dp rich card)  |
  | [Icon] Title  [Wave]  |     |  [Album Art]  Track Title     |
  +-----------------------+     |  Artist Name - Album Name     |
                                |  [<<]   [ || ]   [>>]  (Vol)  |
                                +-------------------------------+

LIVE ACTIVITY STATE ENGINES:
  * Media Playback: Audio wave visualizer, seek scrubber, metadata, and play/pause controls.
  * Active Timer / Stopwatch: Millisecond live counter, pause/reset, and finish alarms.
  * Phone Call Tracker: Ongoing call duration, caller avatar, and one-tap hangup action.
  * Battery Charging Pulse: Animated AGSL liquid glow reacting to charging wattage.
  * Privacy Dots: Hardware indicators (Green = Camera, Orange = Mic) directly inside island margin.

MULTI-PROVIDER AI ARCHITECTURE:
  * Unified `AiProviderClient` interface supporting Server-Sent Events (SSE) streaming.
  * Built-in Providers: Anthropic Claude (3.5/3.7/Opus), OpenAI (GPT-4o), Google Gemini, Groq, Ollama.
  * Failover Circuit Breaker: Automatically cascades down the provider chain upon 429 rate limit
    or network failure without dropping the active chat context.
  * KeyStore Security: Master API keys encrypted using Android KeyStore AES-GCM and stored in DataStore.


----------------------------------------------------------------------------------------------------
5.2. ICON STUDIO & SHADER PIPELINE
----------------------------------------------------------------------------------------------------

Icon Studio executes a real-time GPU shader pipeline (`IconRenderer.kt`) generating consistent
visual styles across any installed icon pack:

  [ Raw App Icon ] ---> [ Mask Geometry ] ---> [ AGSL Shader Pass ] ---> [ Rendered Surface ]
                             |                           |
                             +-- Squircle / Circle       +-- Liquid Glass
                             +-- Hexagon / Pebble        +-- Holographic
                             +-- Teardrop / Star         +-- Duotone Matrix
                                                         +-- Film Grain / Neon

STYLES SUPPORTED:
  1. MATERIAL_YOU: Dynamic tonal extraction matching wallpaper luminance and chrominance.
  2. LIQUID_GLASS: Refractive specular lighting with normal map highlights.
  3. NEON_GLOW: High-saturation edge glow with dark inner contrast.
  4. EMBOSSED: Skeuomorphic directional bevel lighting with soft drop shadows.
  5. DUOTONE: High-contrast dual-color palette mapped to icon luminance.
  6. HOLOGRAPHIC: Animated iridescent color-shifting shimmer effect.
  7. FILM_GRAIN: Tactile analog noise texture overlay with subtle chromatic aberration.


----------------------------------------------------------------------------------------------------
5.3. UNIVERSAL SEARCH ENGINE & MICRO-COMPLICATIONS
----------------------------------------------------------------------------------------------------

Universal Search (`SearchViewModel.kt`) activates via swipe-down or search bar tap, orchestrating
concurrent asynchronous queries across 5 indexed domains:

  [ Search Query Input ]
            |
            +---> [1] Local Apps (Fuzzy Levenshtein & Trigram matching)
            +---> [2] Device Contacts (ContactsContract resolver)
            +---> [3] Media Files (MediaStore indexed search)
            +---> [4] In-App Deep Shortcuts (LauncherApps API)
            +---> [5] Offline Math Evaluator & Unit Converter
            +---> [6] Web Search Intent (Google, DuckDuckGo, Brave, Startpage)

INLINE MICRO-RESULTS:
  * Direct calculations (e.g. `24 * 1024` -> `24,576`).
  * Currency & Timezone conversions (e.g. `$50 to EUR`, `10am EST to CET`).
  * Direct contact calling and SMS actions directly from search results.


----------------------------------------------------------------------------------------------------
5.4. CUSTOM CONTROL CENTER & SYSTEM OVERLAYS
----------------------------------------------------------------------------------------------------

Swiping down from the top-right corner opens the blurred Control Center modal sheet:
  * Network Connectivity: Wi-Fi toggle with `Settings.Panel` fallback, Bluetooth manager.
  * Media Hub: Unified audio output selector and interactive seekbar.
  * Hardware Controls: Flashlight intensity (`CameraManager`), Auto-Rotate, DND mode, Airplane mode.
  * Brightness & Volume Sliders: Continuous gesture sliders with haptic end-stop clicks.
  * Quick Focus Switcher: One-tap toggles for Work, Deep Focus, and Sleep modes.


----------------------------------------------------------------------------------------------------
5.5. FONT STUDIO & ADVANCED MATERIAL YOU THEMING

  * Font Studio: Dynamic Google Fonts catalog downloader and custom TTF/OTF loader.

  * Circadian Color Temperature: Automatic day-to-night temperature shift for eye comfort.
