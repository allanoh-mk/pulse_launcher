# 09 — Gesture System

## Overview

All gestures are customizable in settings.
Each gesture maps to an action.

## Default Gesture Map

| Gesture | Action |
|---------|--------|
| Swipe left/right (home) | Next/previous slide |
| Swipe up (from bottom) | Open app drawer (full list) |
| Swipe down (top-center) | Open search |
| Swipe down (top-right) | Open control center |
| Swipe down (top-left) | Notification shade (system) |
| Long-press (empty space) | Home screen edit mode |
| Long-press (icon) | Context menu / quick actions |
| Long-press (island) | Expand island |
| Tap (island left) | Expand left activity |
| Tap (island right) | Expand right activity |
| Double-tap (empty space) | Open search |
| Double-tap (icon) | Launch app |
| Two-finger pinch (home) | Zoom out (show all slides) |
| Two-finger spread (home) | Zoom in (current slide) |
| Swipe up (on feed card) | Dismiss card |
| Swipe right (on list item) | Show app shortcuts |
| Edge swipe (left) | Back (system) |
| Edge swipe (right) | Recents (system) |
| Three-finger swipe down | Screenshot |
| Hold power button | Assistant (if enabled) |

## Customization

- Settings → Gestures
- Each gesture: tap → pick action from list
- Available actions:
  - Open app (any installed app)
  - Open URL
  - Launch shortcut
  - Toggle (WiFi, BT, Dark Mode, Flashlight)
  - Screenshot
  - Record screen
  - Open search
  - Open control center
  - Open specific slide
  - Trigger focus mode
  - Run macro (sequence of actions)
  - None (disable)

## Multi-Step Macros

- "Good Morning": Turn on WiFi + Data → Open Weather → Play music
- "Work Mode": Enable Focus (Work) → Hide social tiles → Open Slack
- "Sleep": Enable Focus (Sleep) → Set timer 8h → Dark mode → AOD
