# Feed Layout

## Block geometry
Supported defaults: square, wide rectangle, tall rectangle, full width, and provider-defined adaptive blocks.

## User editing
Users can add, remove, reorder, resize, and pin blocks. Layout changes are transactional and undoable.

## Styles
Timeline, Bento, Magazine, Minimal, and Pulse Flow.

Persist layout separately from provider data so changing a provider never destroys placement.
