# Feed Overview

## Purpose
Pulse Feed is Screen 1: a customizable information surface combining personal schedule, lightweight device context, curated information, search-derived content, and user-selected providers.

## Non-negotiables
- Existing Google/Discover-style integration is active and belongs to Feed.
- Providers are modular and independently enabled.
- Layout is user-owned, with a polished default.
- Offline and provider failure states must remain useful.
