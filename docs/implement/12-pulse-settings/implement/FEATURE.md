# Pulse Settings Modules

## Modules
pulse_home, pulse_feed, pulse_bento, pulse_list, pulse_motion, pulse_wallpaper, pulse_icons, pulse_dock, pulse_search, pulse_notifications, pulse_control, pulse_island, pulse_music, pulse_intelligence, pulse_energy.

## Rule
Every visible feature has a discoverable default, advanced customization, reset to default, and import/export where meaningful.

## Theme DNA
A theme records color, typography, corner geometry, spacing, motion, blur, icon shape, and page-specific overrides.

## Persistence
Use versioned settings schemas and migration tests. Never deserialize arbitrary plugin code from a theme file.
