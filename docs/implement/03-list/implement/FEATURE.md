# Pulse List — Focused Niagara-Inspired Screen

## Intent
Screen 3 is a focused favorites-first launcher experience inspired by Niagara's interaction model without copying proprietary branding or assets.

## Layout
- No permanent clock.
- A configurable Pulse Card at the top.
- Favorite applications are primary content.
- User-initiated edge scrolling opens the vertical app list.
- Alphabet edge is selectable left or right.

## Pulse Card
Calendar, weather, music, battery, quote, empty, or Dynamic.

## Search
The icon search on Screen 3 and drawer search call the same Pulse Search engine.

## Notifications
A chevron indicates actionable notification content. Tapping it opens a floating Pulse Reply Card using available Android notification actions.

## Tests
Accessibility labels, left/right-handed alphabet behavior, notification permission denial, and hundreds of installed apps.
